HOCKEY COACH 1.0 公開用PWA

このフォルダの中身を、HTTPS対応のWebサーバーへそのままアップロードしてください。
必要ファイル:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png
- apple-touch-icon.png

iPhone:
1. 公開URLをSafariで開く
2. 共有ボタンを押す
3. 「ホーム画面に追加」
4. 「追加」

Android:
1. 公開URLをChromeで開く
2. メニューから「アプリをインストール」または「ホーム画面に追加」

注意:
現在の1.0は端末内(localStorage)保存です。別端末への自動同期や複数チーム共有には、次段階でログイン＋クラウドDBが必要です。
